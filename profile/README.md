# 🤖 HamBot Discord
 
**HamBot** is a multi-tool Discord bot designed to make your server more powerful and enjoyable.
 
## ✨ Features
 
- 🛡️ **Moderation** — Keep your server safe and clean
- 🎵 **Music** — Play music with playlists, queues and full playback control
- 📋 **Logs** — Track every action happening in your server
- 🎉 **Entertainment** — Fun commands for your community
## 📊 Stats
 
- **1,000+ servers** trust HamBot
- 🇫🇷 🇬🇧 Available in **French & English**
